# 🧠 Mental Health Score Predictor

An end-to-end Machine Learning web application that predicts a user's mental health score (0–10) based on lifestyle habits, academic activities, screen time, sleep patterns, and stress levels.

## 🚀 Live Demo
Frontend: Open Web Application
https://mental-health-score-predictor-2-i1qk.onrender.com/

Backend API: API Documentation (Swagger UI)
https://mental-health-score-predictor-1-dafc.onrender.com/docs


## ✨ Features

- Predicts mental health scores using Machine Learning.
- Analyzes lifestyle and behavioral factors.
- Considers screen time, sleep, study hours, and stress levels.
- Simple and interactive web interface.
- Real-time prediction results.

## 🛠️ Technologies Used

- Python
- Machine Learning
- Pandas & NumPy
- Scikit-learn
- HTML, CSS & JavaScript
- FastAPI
- Render (Deployment)

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Deep07155/Mental-Health-Score-Predictor.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Mental-Health-Score-Predictor
   ```

3. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   ```

4. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Run the application using the appropriate project entry point.
